# MindAgent

MindAgent 是支持群聊交互场景的多用户智能体工作台，面向企业团队线上协同。系统以团队公告资料共享和用户独立 Workspace 隔离为核心，支持多人并发调用、群历史按需查询，以及由 Sub-agent 执行异步长任务。

首个版本采用单机自托管方式，只实现基于 NapCat / OneBot v11 的 QQ 接入；核心保留后续扩展其他 IM 渠道的边界。
